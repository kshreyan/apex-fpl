Read this first This squad is recomputed from scratch every gameweek — it has no memory of a previous squad, so it is not a transfer recommendation (it will not tell you who to sell or buy) and it is not a playable week-to-week plan. Points shown vs. baselines elsewhere on this site do not account for transfer costs or hits, because the model does not model taking any.
